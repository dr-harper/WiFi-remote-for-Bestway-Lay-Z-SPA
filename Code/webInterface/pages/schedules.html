Heating window

Heater turns on at the start time and off at the end time, every day. Useful for off-peak electricity windows — set this to your cheap-rate hours.

How this works: the spa queues two daily commands — set heat ON at start and set heat OFF at end. Existing commands are cleared and rewritten on Save. For finer control (multiple windows, specific days), use the manual command queue in Settings → Spa.
